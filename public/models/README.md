Selected input files: `la_marzocco_coffee_machine (1).glb`, `fellow_electric_kettle.glb`, and `free_pothos_potted_plant_-_money_plant.glb`. The machine variants have the same geometry; the selected version has a smaller embedded texture payload. The ZIP exports are redundant for this app.

Changes: converted from Y up to the café's Z up coordinates, centered and scaled to counter dimensions, enabled shadows and texture filtering, and adjusted pothos leaf alpha testing. The kettle's base remains stationary while its body lifts during the pour-over animation. Meshes and textures are cached and reused across placements.
